# Versi Aman Kantin

Projek Tugas Keamanan Sistem Informasi - P06 Kantin (Versi Aman).

## Deskripsi
Implementasi website sistem kantin dengan penerapan praktik keamanan sistem informasi untuk mencegah kerentanan umum seperti Cross-Site Scripting (XSS), SQL Injection / Input Validation, dan pengamanan formulir transaksi.

## File
- `kantin-aman.html` : Halaman web sistem kantin versi aman.

## Cara Menjalankan
Buka file `kantin-aman.html` langsung di browser favorit Anda (Google Chrome, Microsoft Edge, Firefox, dll).
